# Thawra Alimia v2.0

Local AI Chat with Embedded Termux + FFmpegKit

## Features
- Local AI via Flask in Termux
- FFmpegKit video processing
- Scientific knowledge base
- Unified chat screen App.tsx
- Arabic RTL dark UI
- GitHub Actions APK build

## Build
npm install --legacy-peer-deps && npx expo start

## Termux
pkg install python && pip install flask && python server.py

## CI/CD
1. Download Termux FFmpeg deb aarch64
2. Extract binary from deb
3. Build APK via EAS
4. Create GitHub Release
